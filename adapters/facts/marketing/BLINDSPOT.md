# What `facts/marketing` cannot see

## It says which strings are a label, not whether the label is true

A platform tags a work 百合 for its own reasons, and some of those are commercial. Whether the tag
should admit the work is DEFINITIONS section 6, which weighs several signals. This module answers
one of them and has no opinion on the rest.

## It cannot see a platform that uses another word

The vocabulary is deliberately narrow: the genre's name and its English. A shop that files yuri
under a word nobody here has met will be invisible, and the module will report that confidently.
The recorded memory that categories are not advertised equally is the same point: an absent
category is not absent stock.

## It cannot see a label used as a magazine name

`百合姫` is a magazine and `コミック百合姫` a publisher's line, and both are refused here. That is
correct for a genre tag and wrong if somebody wants to admit on the magazine, which is a different
argument and needs a different question.

## Its narrowness is only tested against what the corpus has met

Every case in the test is a string this project has seen. A false negative from a platform nobody
has looked at yet cannot be tested for, and would show as absence rather than as a failure.
