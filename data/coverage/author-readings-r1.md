# Author readings, round 1

79 names checked. 33 found, 46 not found.

Of the 33 found, 15 contradict the machine guess and 18 confirm it. Two guesses named a
different reading pattern entirely (未幡 stored as ミ ハタ is ミマン; 宙 stored as チュウ is ソラ),
and one guess, 彦田ジュン stored as ヤマモト ウララ, is another person's name altogether; that one
could not be confirmed from any source and is listed as not found.

Nearly all of the found readings come from the National Diet Library, which records
`dcndl:creatorTranscription` beside `dc:creator` on every book it holds. Where NDL marked the
family/given boundary with a comma it is given below as a single space. Where NDL wrote the
transcription as one unbroken token and no other record splits it, the reading is reproduced
unsplit and the note says so, because splitting it would be a guess.

The 46 not-found names are overwhelmingly artists whose only credit is a web chapter, a one-shot
on a publisher's free platform, or a contest entry. None of those produce a catalogued book, so no
cataloguer has ever written the reading down. This is the expected outcome for that population.

版元ドットコム returned HTTP 503 on every attempt during this run and could not be used.

## Method

1. `https://ndlsearch.ndl.go.jp/api/opensearch?creator=<name>` for all 79 names, one request every 1.6s,
   identifying as `yurarium/0.1 (bibliographic database; +https://yurarium.github.io/)`.
   A record counted as a match only when `dc:creator`, with commas and spaces removed, equalled the
   name exactly; NDL's creator parameter matches substrings, so short names return large numbers of
   unrelated people and every match was checked against the other titles on the record.
2. `?title=<example work>` for the 47 names the first pass missed, matching creators the same way.
   This recovered exactly one, 宙, whose one-kanji name is unusable as a creator query.
3. Targeted queries on other known titles by the remaining artists, plus web searches for the
   artist's own X, pixiv, or FANBOX page and for publisher and distributor listings.

Two requests hit HTTP 429 and were repeated. 版元ドットコム returned 503 throughout.
